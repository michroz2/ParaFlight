# Agent Behavior Rules

При каждом шаге:
- Проверяй и сообщай пользователю свой статус чата и памяти (Confidence)!

При каждом шаге (фича или фикс):
- Профессионально обновляй всю необходимую документацию (Documents update)!
- Делай коммит с правильным версионированием!
